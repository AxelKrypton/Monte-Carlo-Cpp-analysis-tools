# Do not merge this branch!

This branch still exists only because it contains some unmerged code that might at some point make sense to port into the codebase.
However, **it is too old and too many modifications have been done on the master without bringing them here**.
Therefore, a merge would been problematic and it is discouraged.
Moreover, the code on the master has been reformatted with clang-format and this would complicate even more the merge.
Indeed, also the history has been rewritten in the repository at some point and this might actually make the merge impossible.
**Refer to [issue #3](https://gitlab.itp.uni-frankfurt.de/sciarra/lqcd-cpp-analysis-tools/issues/3) for more information and to know what to do.**
